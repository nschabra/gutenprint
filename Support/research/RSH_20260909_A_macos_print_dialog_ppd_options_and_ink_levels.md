# Research — macOS Print Dialog PPD Options, Controls, and Ink Levels (`RSH_20260909_A`)

> **Parent:** [`research-master.md`](./research-master.md) · **Status:** `Complete` · **Date:** 2026-09-09

## Question

Why are the "Printer Features" and "Color Matching" info buttons `(i)` in the macOS Print Dialog (`Cmd+P`) unresponsive, why are standard controls (Color vs Black & White, Two-Sided) missing from top-level dialog dropdowns, and how can native macOS print controls, presets, and ink/supplies reporting be reliably delivered for the Canon PIXMA G1010?

## Current Baseline

1. **Active Print Queues**:
   - `Canon_G1010`: USB queue (`usb://Canon/G1010%20series?serial=004049`).
   - `Canon_G1010_2`: AirPrint IPP queue (`dnssd://...` backed by `ippeveprinter` on port 8631).
2. **Current PPD Structure** (`/etc/cups/ppd/Canon_G1010.ppd`):
   - 69 `OpenUI` features generated by Gutenprint.
   - Core options (`ColorModel`, `Duplex`, `MediaType`, `Resolution`) are declared outside any group as raw `special_options`.
   - Remaining options are dumped into groups named `C0L0/Printer Features Common`, `C0L1/Printer Features Extra 1`, `C1L0/Output Control Common`, etc.
   - `*cupsBackSide` is completely absent.
   - `ColorModel` lists 6 raw color spaces (`Gray`, `Black` (inverted), `RGB`, `CMY`, `CMYK`, `KCMY`).
   - `*OPOptionHints` contains legacy slider/spinbox hints with hundreds of discrete millimeter choices (`StpCDOuterDiameter` 184..340).
3. **Observed Failure in macOS UI**:
   - In macOS Sonoma/Sequoia's SwiftUI Print Sheet, only `Color Matching` and `Printer Features` appear under `Printer Options`.
   - Clicking `(i)` on `Printer Features` does nothing or fails silently because the modern SwiftUI sheet parser encounters excessive choices (>150 discrete entries), non-standard group naming (`C0L0`), and unhandled option hints.

## Findings

### 1. Root Cause of Unresponsive `(i)` Info Buttons
Modern macOS print dialogs (macOS Ventura, Sonoma, Sequoia) use a declarative SwiftUI/Cocoa interface:
- When a group like `Printer Features` has >60 sub-options, custom slider hints (`OPOptionHints ... slider input spinbox`), or hundreds of discrete radio values, the popover sheet initialization fails or times out.
- Placing essential options inside standard Apple PPD groups allows macOS to render them directly as native UI controls rather than burying them inside an overloaded `Printer Features` modal sheet.

### 2. Native Top-Level UI Options in macOS
To make controls appear directly in the macOS Print Dialog without requiring sub-sheets:
| Control | PPD Group / Directive | Expected macOS UI Behavior |
| :--- | :--- | :--- |
| **Color vs Black & White** | `*OpenGroup: Color/Color Options`<br>`*OpenUI *ColorModel/Color Mode: PickOne`<br>Values: `Gray/Black and White`, `RGB/Color` | Appears as a native Color Mode dropdown / toggle. |
| **Two-Sided (Duplex)** | `*cupsBackSide: Normal`<br>`*OpenUI *Duplex/Two-Sided Printing: PickOne`<br>`*DefaultDuplex: None` | Enables native "Two-Sided" checkbox / popup under Layout. |
| **Media Type & Quality** | `*OpenGroup: Media/Media and Quality`<br>`*OpenUI *MediaType/Media Type: PickOne`<br>`*OpenUI *StpQuality/Print Quality: PickOne` | Appears as native "Media & Quality" section with dropdowns. |

### 3. Apple Print Presets (`*APPrinterPreset`)
macOS parses `*APPrinterPreset` directives directly into the top-level **Presets** dropdown:
- A clean preset definition sets `*ColorModel`, `*MediaType`, and `*StpQuality`.
- Standard presets needed:
  1. `Color_Standard` ("Default Color")
  2. `BW_Standard` ("Black and White")
  3. `Photo_Best` ("High Quality Photo")
  4. `Draft_BW` ("Draft Black and White")
- Avoid duplicate preset keys (e.g. previous PPD had multiple `Photo` keys which caused PPD validation warnings).

### 4. Ink & Supplies Status for Canon G1010
- Canon G1010 is an ink-tank printer connected via USB. It lacks network SNMP, but its USB device descriptor / status packets report ink warnings and hardware state.
- In CUPS, ink levels are reported via `ATTR: marker-levels=... marker-names=... marker-types=... marker-colors=...`.
- Setting `cupsSNMPSupplies: False` prevents CUPS from stalling on USB queues.
- Visual ink tank level monitoring is standard on MegaTank, while estimated ink levels or cartridge status can be provided via `g1010-ctl` status utility.
